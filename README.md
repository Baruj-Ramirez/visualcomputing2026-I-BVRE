**COMMITS**:

Se utilizara la siguiente notacion para los commits en ingles:
- `feat:` Para una nueva característica (Avance de codigos para los talleres o proyecto).
- `fix:` Para una corrección de un error (bug fix).
- `docs:` Para cambios en la documentación solamente.
-	`style:` Para cambios de estilo de código (formato, espacios en blanco, punto y coma, etc.) que no afectan el significado del código.
- `refactor:` Para refactorizaciones de código que no corrigen un error ni añaden una característica.
- `chore:` Para tareas de mantenimiento, cambios menores o ajustes que no afectan el código de producción.
